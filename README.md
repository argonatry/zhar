# Жар — демо-сайт ресторана

Одностраничный сайт ресторана «Жар» (Киев, мясо на огне) для портфолио: чистый HTML + CSS + JS, без сборщика.
GSAP + ScrollTrigger + SplitText и Lenis подключены с CDN. Название, меню, цены, адрес и телефон вымышленные.
Форма брони ничего не отправляет и не сохраняет — после проверки показывает сообщение «Ми передзвонимо».

## Запуск
```bash
python -m http.server 8000
```
Открыть http://localhost:8000 (через `file://` не откроется — скрипты подключены как модули).

## Проверка
```bash
npm install                      # один раз, ставит Playwright
npx playwright install chromium  # один раз
node scripts/shots.mjs           # сервер должен быть запущен
```
Скрипт прокручивает страницу на ширине 375 / 768 / 1440 px и складывает кадры в `shots/`.
Ещё он снимает полную страницу в режиме reduced motion и с выключенным JS, проверяет, что кнопка брони
видна на первом экране, прогоняет форму и печатает ошибки консоли, 404 и горизонтальный скролл, если они есть.

## Структура
- `index.html` — вся разметка и тексты
- `css/tokens.css` — цвета, шрифты, размеры; `css/base.css` — общее; `css/sections.css` — секции
- `js/main.js` — точка входа; `js/anim/*.js` — по файлу на секцию
- `js/form.js` — форма брони; `js/select.js` — свои выпадающие списки; `js/ui.js` — закреплённая кнопка на телефоне и карта
- `assets/img/` — фото в WebP; источники — в `CREDITS.md`
