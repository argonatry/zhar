# CLAUDE.md

## О проекте
Демо-сайт ресторана «Жар» (Киев, мясо на огне, вечерний формат) для портфолио: его показывают владельцам ресторанов.
Владелец смотрит с телефона 20–30 секунд, поэтому первый экран и плавность на мобильном важнее числа секций.
Название, меню, цены, адрес и телефон вымышленные. Отзывы, награды и цифры не придумывать: нет данных — нет секции.
Язык текстов на сайте: украинский. Знака «₴» в шрифтах нет — цены пишем числом, валюта указана в примечании к меню.

## Стек
- Чистый HTML + CSS + JS, без сборщика. Устроено так же, как `../cofe/`.
- CDN jsDelivr, точные версии: gsap 3.15.1 (gsap, ScrollTrigger, SplitText), lenis 1.3.27.
- Шрифты Google Fonts: Dela Gothic One (заголовки, цены), Onest 400/500/600 (текст).

## Команды
- Сервер: `python -m http.server 8000`, открыть http://localhost:8000 (не `file://`).
- Проверка: `node scripts/shots.mjs` → `shots/`. Снимает 375 / 768 / 1440 px, reduced motion и вариант без JS,
  проверяет кнопку брони на первом экране, форму, консоль, 404 и горизонтальный скролл.

## Структура
```
index.html
css/tokens.css     — цвета, шрифты, шкала размеров. Цвета и шрифты задаются только здесь
css/base.css       — сброс, типографика, кнопки, полоска «температуры», закреплённая кнопка
css/sections.css   — стили секций в порядке index.html
js/main.js         — точка входа: плагины, Lenis, gsap.matchMedia, запуск секций
js/anim/*.js       — по файлу на секцию, каждый экспортирует init…()
js/form.js         — форма брони (без бэкенда, ничего не отправляет)
js/ui.js           — закреплённая кнопка брони на телефоне, включение карты по клику
assets/img/        — только WebP, до 300 КБ
scripts/shots.mjs  — скриншоты и автопроверки
```

## Дизайн-система «температура»
- Палитра: уголь `#140e0b` (фон), сажа `#221915` (меню), пепел `#e9dfd2` (текст), дым `#a0958a` (вторичный текст),
  жар `#ff4b1f` (акцент, секция брони), пламя `#ffb23e` (hover, свечение).
- Страница «разгорается» сверху вниз: тёмные секции → раскалённая секция брони. Полоска сверху — прогресс скролла.
- Один запоминающийся элемент: слово «ЖАР» в hero, буквы — окно в фото углей (`background-clip: text`),
  под ними «холодный» слой, за ними дышащее свечение. Остальное спокойное.
- Фото и кнопки без скруглений, без карточек с тенями, всё по левому краю.
- Анимации медленные и тяжёлые: шторки `clip-path`, строки из-под маски. У каждой секции свой приём.

## Правила анимаций
- Анимировать только `transform`, `opacity`, `clip-path`.
- Всё внутри `gsap.matchMedia()` в `main.js`: десктоп (≥900px), телефон, `prefers-reduced-motion`.
- Телефон легче: нет искр (canvas), нет параллакса, нет пина галереи (обычная лента со свайпом),
  шторка брони играет один раз, а не по скроллу.
- Контент виден без JS и при reduced motion: скрытые стартовые состояния — только под `.js:not(.reduced):not(.is-ready)`
  или через `gsap.set`. Шторку брони создаёт JS.
- Если CDN не загрузился, через 4 с страховка в `<head>` ставит класс `reduced`.
- Форма, закреплённая кнопка и карта не зависят от GSAP.

## Заметки
- Unsplash отдаёт 403 автоматическому браузеру на странице поиска. Защиту не обходить: искать фото обычным поиском
  по `site:unsplash.com/photos`, качать с `images.unsplash.com/photo-ID?fm=webp&q=..&w=..&h=..&fit=crop`.
- SplitText игнорирует `&nbsp;` при разбивке на строки: нужный перенос в заголовке ставить через `<br>`.
- `gsap.from` оставляет inline-transform и перебивает hover из CSS — у строк меню стоит `clearProps: 'all'`.
